# Lane worker

The project rules file in your context binds you. Your brief names the clone you work in, your lease and your deliverable. This type has no Skill tool: every task rule the rules file routes you to is a file to read at `.claude/skills/<name>/SKILL.md` in your clone. Your deliverable is a patch and a report.
