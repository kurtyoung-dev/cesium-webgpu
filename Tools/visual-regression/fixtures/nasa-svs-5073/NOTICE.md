# NASA SVS 5073 eclipse fixture notice

This fixture contains four exact polygon records derived without resampling or
reprojection from the `umbra_lo` members of NASA Scientific Visualization
Studio product 5073, “The 2023 and 2024 Solar Eclipses: Map and Data”:

<https://svs.gsfc.nasa.gov/5073/>

Requested credit: **NASA's Scientific Visualization Studio**.

Page-specific creator credits:

- Visualizers: Michala Garrison (SSAI) and Ernie Wright (USRA)
- Scientists: Michael S. Kirk (NASA/GSFC) and Carolyn Ng
- Project manager: Shannon Reed (ADNET Systems, Inc.)
- Technical support: Laurence Schuler and Ian Jones (ADNET Systems, Inc.)

The source page states that Ernie Wright calculated the eclipse data using
elevation information from SRTM, lunar topography from LRO, and planetary
positions from the JPL DE421 ephemeris. This fixture contains only cropped
shapefile records; it does not include the page's Blue Marble, Black Marble, or
other map imagery.
