## Tier 1 — Correctness bugs that bite real/default usage

1. **NEW-MODEL-DIRECT-BRDF-PARITY** (M) — glTF models mis-shaded vs WebGL (missing Smith-joint visibility + f90 in the direct-light BRDF).
2. **NEW-MATAPPEARANCE-DIFFUSE-PARITY** (M) — lit MaterialAppearance primitives render darker than WebGL `czm_phong` (ad-hoc Blinn-Phong term in the `*Lit.wgsl` family; surfaced Batch 326).
3. **NEW-TAA-PROJECTION-JITTER-OVERWRITTEN** (M) — per-frame `_updateFrustumUniforms` recompute clobbers the TAA sub-pixel jitter before any draw → static-edge AA never reaches the GPU.
4. **DP-H37** (S) — glTF `COLOR_0` as VEC3 declared `float32x4` → shader reads next vertex's `.r` as alpha → flickery alpha tracking vertex order. *(quick win)*
5. **NEW-DIRTY-CONSUME-POINT** (S) — `PointPrimitiveCollection` never calls `_consumeDirtyState()` → rebuild gate fires every frame. *(quick win)*

## Tier 2 — Picking (functional API holes)

6. **DP-H44** (M) — globe surface emits no pick-ID on WebGPU → terrain invisible to `scene.pick`.
7. **NEW-WEBGPU-PICK-COLD-SYNC-STALENESS** (M) — first synchronous `scene.pick()` against a fresh pick FBO returns undefined for any primitive (async readback is one frame stale; surfaced Batch 323, needs design).
8. **DP-H46** (M) — `scene.pickMetadata` entirely unwired (`frameState.pickingMetadata` never consumed) → always null.

## Tier 3 — Visual-parity holes (user-visible)

9. **C-R8-SCENE2D-JITTER** (L) — collections invisible in 2D / Columbus View (camera-shift + projected-frame RTE encoding; `probe-collections-2dcv-morph` all-zero — last big collections visual hole).
10. **NEW-CSM-CASCADE-GROUND-FIT** (M) — coarse sawtooth globe shadow edge vs WebGL's tight-fit map; clamp cascade far at the ground before `_fitBoundingSphere`.
11. **NEW-SPLAT-MULTIFRUSTUM-DEPTH-COMPOSE** (M) — single-pack full-frustum Gaussian-splat command occluded by opaque geometry in multi-frustum scenes (UBO not re-packed per slice).
12. **MORPH-EXAG-SKIRTS** (M) — vertical exaggeration dropped during MORPHING/COLUMBUS_VIEW (gated SCENE3D-only); needs WebGL-faithful skirt handling for the planar legs.
13. **NEW-CLOUD-IMPOSTOR-FS-PARITY** (M) — WebGPU cloud FS is a 2D-noise impostor vs WebGL ellipsoid raymarch (~4–5× per-cloud divergence; `maximumSize`/`slice` ignored).
14. **NEW-WEBGPU-SKYBOX-HDR-FAINT-STAR-PARITY** (M) — under HDR+bloom the whole WebGPU night sky is far dimmer than WebGL. **Root cause corrected 2026-06-22: the shared HDR tonemap/auto-exposure/bloom path, NOT the cubemap decode.** HDR-only (SDR byte-identical). Needs broad HDR regression coverage (model + globe), not a star-renderer tweak.

## Tier 4 — Infrastructure leverage (unblocks future work)

15. **NEW-WEBGPU-COMPUTE-ENGINE-WIRING** (M) — `WebGPUContext` never instantiates a `WebGPUComputeEngine`, so general compute (atmosphere-LUT consumption, frustum cull, point-cloud sort/LOD, GPU sort keys, Hi-Z, polygon SDF) is a runtime no-op. (NB: the dynamic env-map runs its OWN `beginComputePass`, so SH IBL etc. are unaffected — this gates the LUT/cull/sort consumers.)
16. **NEW-WEBGPU-UNIFORMSTATE-VIEWPORT** (M) — `UniformState.viewport` only seeded by the WebGL path → `viewportOrthographic`/`viewportTransformation` stay identity on WebGPU; every screen-space WGSL shader hand-builds them.
17. **DP-H47** (L) — no shared `csm_atmosphere*` auto-uniform suite; SkyAtmosphere/Clouds/GlobeGroundAtmosphere/ModelAtmosphere each hand-roll their `atmosphericConditions` pull → a custom `scene.atmosphere` param applies in one renderer and is silently defaulted in another.
18. **NEW-MATERIAL-PER-BACKEND-SHADER-SOURCE** (M) — `ViewportQuad` + Material-driven primitives still branch on `context.isWebGPU` for WGSL-vs-GLSL; needs a per-backend `getShaderSource()`/`getUniformMap()` virtual (last sanctioned backend branch in scene logic).

## Tier 5 — Feature gaps + high-value visual

19. **DP-H18** (M) — `depthFailAppearance` entirely unimplemented on WebGPU (no twin shader/pipeline/uniforms) → see-through highlighting of occluded primitives broken.
20. **NEW-MODEL-IBL-KTX2-CUBEMAP-WEBGPU** (M) — authored KTX2 specular env maps don't load on the WebGPU context → models fall back to procedural IBL.
21. **NEW-POLYLINE-APPEARANCE-PRIMITIVE-WEBGPU** (M) — color + material slices shipped (Batches 343/344); picking, 2D/CV/morph, effects/log-depth, and textured polyline materials still open.
22. **NEW-ENTITY-GPU-KEYFRAME-KERNEL** (L) — CZML `SampledPositionProperty` entities still use the per-frame CPU interpolation lane; the auto Entity→GPU-keyframe-buffer bridge over the shipped `SampledPositionKernel` substrate is unbuilt.
23. **NEW-MODEL-MORPH-TANGENT-DELTAS** (S) — WebGPU morph interleaves only position+normal deltas; a normal-mapped morphed model keeps its rest-pose tangent frame → tangent-space normal drifts as the mesh deforms.
24. **NEW-VOLUMETRIC-CLOUD-LAYERS** (L) — raymarched volumetric clouds (Perlin-Worley + weather map + Beer-powder + dual-lobe HG + multi-scatter) — Track V headline.
25. **DP-H48** (S) — `temeToPseudoFixed` never reaches a shader → star-field/skybox uses the equinox-aligned basis, stars don't rotate with the Earth day-cycle (status unverified).
