   - **Per-file fix:** `ambient = 0.15` → `0.5`; `diffuse = NdotL*0.7` → `0.5*(max(dot(normal,vec3(0,0,1)),0)+max(dot(normal,vec3(0,1,0)),0))`; keep specular + shadow/CSM/clustered/atmosphere wiring + `lighting = ambient + direct` (= `0.5 + 0.5·lambert + spec`).
