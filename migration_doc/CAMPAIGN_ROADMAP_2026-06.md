The main-thread OFFLOADABLE encode+upload ceiling on the flat-buffer substrate (`BufferPointCollection` RTE-encode + GPU-upload, shared with the compute-instance WebGL2 cpuKernel + the Batch-300 entity bulk fast-path) is **~89k @60fps / ~187k @30fps (WebGPU)** and **~77k @60fps / ~154k @30fps (WebGL)** objects/frame, measured at 10k/50k/100k/250k with a full-collection arbitrary update every frame — on the CONSERVATIVE JS-fround path (the SIMD kernel doesn't load in the bundle and would only raise these).
