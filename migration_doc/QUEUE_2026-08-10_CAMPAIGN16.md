   asserts on is not a comment — it is an interface, and rewriting it turns a
   green suite red. Sweep the whole spec/probe fleet for anchors into your
   shard's files and report **three classes**, not one:
   - **(a) grammar-matching literals** — any string literal whose text matches
     `Tools/c16/lib/marker-grammar.mjs`;
   - **(b) regex literals** — `assert.match(src, /C13-39/)` is invisible to a
     string-literal-only scan; that exact shape is how
     `cloud-march-emission.spec.mjs` survived C16-06's sweep and went red on the
     first post-rewrite spec run;
   - **(c) containment verbs applied to comment text** — `indexOf`/`includes`
     used as a **block locator**, which reads as ordinary source-slicing rather
     than as an assertion; C16-07 found two of these in `ground-fog-band.spec.mjs`.
   **NO minimum literal length.** C16-06 used a 12-char floor to suppress noise
   and a bare tracker id is 6-8 characters, so the floor silently dropped the
   very thing being hunted. Grammar-aware, length-blind, or it does not count.
2. **Mutation controls must be proven NON-PREFIX.** A mutant that merely
   truncates or prefixes the text can pass for reasons unrelated to the rule
   under test. State, per control, why the mutation is not a prefix of the
   original and what it would take for the control to fire on an unrelated
   change.
3. **Comment-only-diff verifier byte-identical.** C16 changes comments, never
   code. Any code delta in a rewrite shard is a defect in the shard, not an
   improvement — file it as a follow-up row (`C16-08a` is the pattern) and leave
   the code alone.
4. **DEV_NOTES banking lands in the SAME batch.** Knowledge extracted out of the
   removed comments goes into `DEV_NOTES_<subsystem>.md` **in the batch that
   removes it**. A later batch is not an option: the batch boundary is exactly
   where the knowledge is lost.
5. **Cleanlist ratchet.** Add every file you cleaned to
   `Tools/c16/comment-marker-cleanlist.txt` in the same batch. Findings under
   clean-listed paths are ERRORS, not warnings — that is what makes the campaign
   monotonic and what stops a later batch from quietly regrowing the debt.
6. **Census-delta obligation.** Record, in the row's status cell, the census
   before and after your shard (`node Tools/c16/comment-marker-guard.mjs
   --census --strict`), with the file count, the marker count, and the per-rule
   delta. A shard that cannot state its own delta has not measured itself.
7. **`npm run build-docs` clean** when the shard touches exported API.
